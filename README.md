# 绍兴五日游行程规划

这是一个展示绍兴五日游行程规划的网页项目。网站包含了详细的行程安排、实时天气、地图导航等功能。

## 功能特点

- 详细的五日游行程安排
- 集成高德地图，支持导航和位置查看
- 实时天气信息显示
- 景点图片展示
- 支持打车和周边搜索
- 响应式设计，支持移动端访问

## 技术栈

- HTML5
- CSS3
- JavaScript
- 高德地图 API

## 本地运行

1. 克隆项目到本地：
```bash
git clone https://github.com/CocoPeng1018/shaoxing-travel.git
```

2. 进入项目目录：
```bash
cd shaoxing-travel
```

3. 使用本地服务器运行项目，例如使用 Python 的简单 HTTP 服务器：
```bash
python -m http.server 8000
```

4. 在浏览器中访问：`http://localhost:8000`
